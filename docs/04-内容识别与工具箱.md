# 04 · 内容识别与工具箱

这是 DevClip 与普通剪贴板管理器的分界线：**不只是存下来，而是理解它**。

## 识别顺序

`detect.rs` 必须**按顺序**判定，先匹配到的胜出。顺序错了会把 SQL 认成 code、把 JSON 认成 text。

```
1. image            —— 非文本 flavor
2. json             —— 可被解析为 JSON
3. jwt              —— 三段 base64url，段1/段2 可解出含 typ/alg 等字段
4. uuid             —— 标准 8-4-4-4-12
5. ip               —— IPv4 / IPv6（注意要和 UUID 区分，UUID 有连字符）
6. url              —— 有 scheme 的合法 URL
7. commit           —— `^[0-9a-f]{7,40}$`（先排除 纯数字误判）
8. exception        —— 匹配到异常栈特征
9. sql              —— 命中 SQL 关键字组合
10. base64          —— 长度 % 4 == 0 且解码成功且解码结果可打印
11. markdown        —— 含 `^#{1,6} `、`**`、`](`、`- [ ]` 等结构
12. code            —— 多行 + 缩进 + 常见语言特征
13. text            —— 兜底
```

### 每条规则的具体判据

| 类型 | 判据 | 注意 |
|---|---|---|
| `json` | `serde_json::from_str::<Value>()` 成功 | 失败则继续往下 |
| `jwt` | `split('.').count() == 3` + 每段是合法 base64url + header 解出 JSON 含 `alg` | **三段但解不出 header 的不算 JWT**（普通 base64 也可能三段） |
| `uuid` | 正则 `^[0-9a-fA-F]{8}-([0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12}$` | |
| `ip` | 用 `std::net::IpAddr::from_str` | IPv6 优先判断，因为不含点 |
| `url` | `url::Url::parse` 成功 + scheme ∈ {http, https, ftp, ws, wss, file, git} | **`git@github.com:user/repo.git` 要单独用 SSH 正则匹配** |
| `commit` | `^[0-9a-f]{7,40}$` | 纯数字全匹配时要排除（可能是订单号） |
| `exception` | 命中 `^[\w.$]+(Exception|Error)\b` 或 `at [\w.$]+\([\w]+\.java:\d+\)` 或 `Traceback (most recent call last)` | 多语言特征并列 |
| `sql` | 至少 2 个关键字（`SELECT` `FROM` `WHERE` `JOIN` `INSERT` `UPDATE` `DELETE` `CREATE TABLE` `ALTER` `GROUP BY`…）**且** 大小写不敏感 | 单个 "select" 不算，必须 2 个 |
| `base64` | 长度 ≥ 8、长度 % 4 == 0、字符集合法、解码后 UTF-8 且可打印 | 排除本身就是纯数字/纯十六进制的情况 |
| `markdown` | 行首 `#{1,6} `、`` ``` ``、`](` 链接、`- [ ]` 任务项，至少命中 2 类 | |
| `code` | 行数 ≥ 3，且（存在 2 空格以上缩进 / 命中语言关键字 / 命中 `{` `}` `;` 配对） | 放在 SQL 之后 |

**`source_app` 可以加权判定。** 复制来源是 `IntelliJ IDEA` / `VS Code` / `DataGrip` 时，即使是 code，也尝试更激进地识别为 sql / json / code。这需要平台提供前台应用信息（macOS 有 `NSWorkspace.frontmostApplication`），是 P1 的差异化点。

## 工具箱操作矩阵

识别出类型后，UI 在选中条目时展示可执行操作。

### JSON

| 操作 | 说明 |
|---|---|
| Format | 2 空格缩进美化 |
| Minify | 压缩成一行 |
| Sort Keys | 按 key 字母序排序（便于 diff） |
| Beautify (4 spaces) | 4 空格缩进 |
| Copy | 写回剪贴板 |

### JWT

| 操作 | 说明 |
|---|---|
| Decode Header | 解第一段，可展开 JSON |
| Decode Payload | 解第二段，可展开 JSON |
| Verify Exp | 检查 `exp` 是否已过期，显示剩余时长 |
| Copy Token / Copy Claim | 复制原始值或指定 claim |

注意：JWT 是 base64，**不是加密**。UI 上要明确标注这一点，避免用户误判安全性。

### SQL

| 操作 | 说明 |
|---|---|
| Format | 大小写规范化关键字、缩进对齐 |
| Explain Table | 解析出表名列表（第一版只做提取，不连数据库） |
| Upper/Lower Keywords | 关键字统一大写或小写 |
| Copy | 写回剪贴板 |

### Base64

| 操作 | 说明 |
|---|---|
| Decode | 解码 |
| Encode | 对当前内容编码 |
| Decode → Copy | 一步到位 |
| Url-safe 变体 | Base64URL 模式 |

### URL

| 操作 | 说明 |
|---|---|
| Open in Browser | |
| Copy without query | 去掉 `?...` |
| Extract domain | |
| Unshorten | 展开短链（需要网络，P2） |

### UUID

| 操作 | 说明 |
|---|---|
| Upper / Lower / No dashes | 三种常见格式互转 |

### IP

| 操作 | 说明 |
|---|---|
| Copy IP | |
| Ping | （P2，需要网络） |
| 格式转换 | 十进制 ↔ 十六进制 ↔ 二进制 |

### 通用（所有文本类型）

| 操作 | 说明 |
|---|---|

## 动作注册表（Rust 侧）

用注册表而不是一长串 `match`，这样加新类型不用动分发逻辑。

```rust
pub struct ToolboxAction {
    pub id: &'static str,
    pub label: &'static str,
    pub applies_to: &'static [ContentType],
    pub run: fn(&str) -> Result<String, AppError>,  // 输入原文，返回结果
}
```

```rust
pub fn register() -> &'static [ToolboxAction] {
    &[
        ToolboxAction { id: "json.format",  label: "Format",     applies_to: &[Json], run: json::format  },
        ToolboxAction { id: "json.minify",  label: "Minify",     applies_to: &[Json], run: json::minify  },
        ToolboxAction { id: "jwt.decode_header",  label: "Decode Header",  applies_to: &[Jwt], run: jwt::decode_header },
        ToolboxAction { id: "sql.format",  label: "Format",     applies_to: &[Sql], run: sql::format  },
        // ...
    ]
}
```

前端调用 `availableActions(contentType)` 拿到该类型可用的操作列表，UI 直接渲染。**这样前端不需要硬编码任何类型判断逻辑。**

## 错误处理约定

所有 toolbox 动作返回 `Result<String, AppError>`，错误要**可读且能指导下一步**：

- ✗ `不是合法的 JSON，无法格式化` —— 而不是 `parse error at line 1 column 5`
- ✗ `JWT payload 解码失败，可能不是 JWT` —— 而不是 `InvalidPadding`
- ✗ `Base64 长度不是 4 的倍数（当前 13）` —— 给出具体数值

失败时在 UI 上就地展示错误，不弹 toast（用户在连续试用多个操作，toast 会打断）。
