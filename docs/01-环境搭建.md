# 01 · 环境搭建

> 本文命令基于 **Linux Mint 22.x**（Ubuntu 24.04 底座）编写。
> macOS / Windows 的差异见文末速查表。
>
> **状态：以下命令均未在本机执行验证过**（当前机器未安装任何工具链）。
> 首次执行时若遇到报错，请更新本文并在提交信息中标注。

---

## 0. 检查当前状态

```bash
node -v    # 期望 v20+，推荐 v22 LTS
pnpm -v    # 期望 9+
cargo -V   # 期望 1.7x+
```
三条都报 `command not found` 就是还没装，继续往下。

---

## 1. 系统依赖（Tauri 2 需要）

Tauri 2 基于 `webkit2gtk-4.1`，这是 Linux 上最容易踩坑的一步。

```bash
sudo apt update
sudo apt install -y \
  build-essential \
  curl \
  wget \
  file \
  libxdo-dev \
  libssl-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  libwebkit2gtk-4.1-dev \
  patchelf
```

**`libwebkit2gtk-4.1-dev` 是关键项。** 注意是 `4.1` 不是 `4.0`——Tauri 2 要求 4.1，Mint 22 自带仓库已提供。

Linux 端还会用到 X11 剪贴板与模拟按键相关库，阶段 3 补装：

```bash
sudo apt install -y libx11-dev libxtst-dev libxcb-randr0-dev
```

## 2. Node.js（建议用 nvm 管理）

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc

nvm install 22
nvm alias default 22
node -v
```

> 不想用 nvm 也可以 `sudo apt install nodejs npm`，但 Ubuntu 仓库里的 Node 版本偏旧，Tauri 2 要求 **Node ≥ 20**，apt 源可能不满足。**推荐 nvm。**

### pnpm（用 corepack，不单独 npm install）

```bash
corepack enable
corepack prepare pnpm@latest --activate
pnpm -v
```

以后换 Node 版本后如果 `pnpm` 失效，重新执行一次 `corepack enable`。

---

## 3. Rust（用 rustup）

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

rustup update stable
rustup default stable
cargo -V && rustc -V
```

**不要用 `sudo apt install rustc`**：发行版的 Rust 通常落后半年以上，而 `sqlx` / `rusqlite` / `tauri` 对 MSRV 有要求，太旧会编译失败。

### 验证 Rust 工具链

```bash
mkdir -p ~/tmp/rust-check && cd ~/tmp/rust-check
cargo new hello && cd hello
cargo run
```

## 4. 初始化工程

环境就绪后，在项目根目录执行：

```bash
cd ~/Documents/code/devClip
pnpm create tauri-app@latest . --template react-ts
pnpm install
pnpm tauri dev
```

首次执行 `create-tauri-app` 的交互式提问，建议这样填：

| 提问 | 选择 |
|---|---|
| Project Name | `devclip`（或直接接受默认） |
| Frontend Language | `TypeScript / JavaScript` |
| Package Manager | `pnpm` |
| UI Template | `React` |
| Add Tailwind? | 先不用（v4 手动装，见下） |

**重要：一次性用 `create-tauri-app` 建出完整结构，不要先做纯 Vite 再迁移 Tauri。** 迁移会浪费一整轮时间。前端在阶段 1 依然可以纯 TS 开发，靠端口-适配器隔离（见 [02 架构设计](02-架构设计.md)）。

### Tailwind v4（手动装）

```bash
pnpm add tailwindcss @tailwindcss/vite
```

`vite.config.ts`：

```ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

`src/index.css`（v4 是 CSS-first 配置，没有 tailwind.config.js）：

```css
@import "tailwindcss";
```

### shadcn/ui + cmdk

```bash
pnpm dlx shadcn@latest init
pnpm dlx shadcn@latest add button input dialog
pnpm add cmdk zustand
```

## 5. Tauri 2 依赖的 Rust crate

`src-tauri/Cargo.toml` 最终需要的核心依赖：

```toml
[dependencies]
tauri = { version = "2", features = ["tray-icon", "image-png"] }
tauri-plugin-clipboard-manager = "2"
tauri-plugin-global-shortcut  = "2"
tauri-plugin-single-instance  = "2"
serde = { version = "1", features = ["derive"] }
serde_json = "1"
tokio = { version = "1", features = ["full"] }
rusqlite = { version = "0.3x", features = ["bundled", "backup"] }  # bundled 自带 FTS5
blake3 = "1"
anyhow = "1"
thiserror = "2"
parking_lot = "0.12"
tracing = "0.1"
tracing-subscriber = "0.3"
```

各插件的职责：

| crate | 职责 | 备注 |
|---|---|---|
| `tauri-plugin-clipboard-manager` | 读 / 写剪贴板 | **只有 read/write，没有 change 事件**，监听必须自己写 |
| `tauri-plugin-global-shortcut` | 全局快捷键注册 | 注册失败要能把错误传回前端 |
| `tauri-plugin-single-instance` | 单实例 | 防止重复启动导致双份监听 |
| `tauri-plugin-autostart` | 开机自启 | P1，可后加 |
| `tauri-plugin-updater` | 应用内更新 | P1 |

## 6. 验收

```bash
pnpm tauri dev
```

应出现一个空白窗口，控制台无 `webkit2gtk` 相关报错。

**Linux 上如果窗口白屏或报 `Cannot allocate GL context`**，在容器 / 虚拟机 / 远程 SSH 环境下是正常现象——GPU 不可用。临时绕过：

```bash
WEBKIT_DISABLE_COMPOSITING_MODE=1 pnpm tauri dev
```
这只是本地开发期的绕过方式，不影响发布产物。

## 7. 平台速查

### macOS
- 只需 Node / pnpm / Rust（`curl ... | sh`），无系统依赖。
- 模拟粘贴需要**辅助功能(Accessibility)授权** → 阶段 5 会遇到，需提前设计引导流程。
- 分发需要 Apple 开发者账号做公证(notarization)，见 [05 平台差异与风险](05-平台差异与风险.md)。

### Windows
- 需安装 [RustVC++ 构建工具](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（选"使用 C++ 的桌面开发"工作负载）+ WebView2。
- WebView2 在 Win11 自带，Win10 可能需单独装。
- 推荐在 **PowerShell 7** 里操作。

### Linux 补充
- 本项目 Linux 端依赖 **X11**（`DISPLAY`）。Mint 默认 Xorg 会话满足。
- 若切到 Wayland 会话，剪贴板监听将失效 → 见 [05 平台差异与风险](05-平台差异与风险.md)。

## 8. 日常命令

| 命令 | 作用 |
|---|---|
| `pnpm tauri dev` | 开发模式（前端 HMR + Rust 热重载） |
| `pnpm tauri build` | 生产构建，产物在 `src-tauri/target/release/bundle/` |
| `cargo test` （在 `src-tauri/` 下） | 跑 Rust 单元测试 |
| `cargo clippy` | Rust lint |
| `pnpm lint` / `pnpm format` | 前端 lint / 格式化 |

Rust 侧单独编译迭代（比重开 `tauri dev` 快很多）：

```bash
cd src-tauri && cargo check
```
